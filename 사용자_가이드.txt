================================================================
  월드컵 예측 리더보드 — 사용자(운영자) 가이드
================================================================
  대상: 캠프를 운영하면서 이 사이트를 직접 다루는 사람
  (코드를 안 고쳐도 되는, 운영 중에 알아야 할 내용 위주)


[ 1 ] 버전 관리를 꼭 챙겨야 하는 이유
───────────────────────────────────────────────────────────────
지금 배포된 사이트는 "재시작되면 데이터가 날아갈 수 있는" 구조입니다.

  · 참가자가 CSV를 제출하면 → 배포된 서버(컨테이너)의 디스크에
    저장됨. 본인 로컬 컴퓨터가 아니라 원격 서버에 저장되는 것.
  · 이 서버는 "휘발성"입니다. 앱을 재배포하거나 "Reboot app"을
    누르면, GitHub 저장소에 커밋되지 않은 데이터는 전부 사라집니다.
  · 즉, 캠프 진행 중 참가자들이 제출한 CSV가 GitHub에 커밋되지
    않은 채로 쌓여 있다면, 실수로 재배포/재부팅하는 순간 그동안
    쌓인 제출물이 통째로 사라질 수 있습니다.

지금 할 수 있는 가장 간단한 예방책:

  1) 캠프 진행 중간중간, submissions/ 폴더를 GitHub에 커밋해두기
     (개발자에게 요청하거나 직접 git add/commit/push)
  2) 절대 필요하지 않은 한 "Reboot app"을 함부로 누르지 않기 —
     커밋 안 된 제출물이 있다면 먼저 백업부터
  3) 캠프가 끝나면 최종 제출 데이터를 한 번 더 커밋해서 보존

※ 자동으로 백업되는 기능은 아직 없습니다. Google Sheets 연동이나
   GitHub 자동 커밋 같은 방법을 검토했지만 아직 적용 안 했습니다.
   참가자가 많아지거나 캠프 기간이 길어지면 이 부분을 자동화하는
   걸 권장합니다.


[ 2 ] 대시보드 한눈에 보기
───────────────────────────────────────────────────────────────

  [상단] 채점 기준
  · 어떤 예측이 몇 점인지 설명하는 표. 항상 펼쳐진 상태로 시작.

  [그다음] 📊 조별리그 순위
  · 실제 월드컵 조별리그(A조~L조) 현재 순위표.
  · 드롭다운으로 조를 선택하면 그 조의 순위/경기/승/무/패/
    득점/실점/득실차/승점이 표로 나옵니다.
  · 연두색 음영 = 그 조 1·2위 (16강 진출권에 해당하는 자리).
  · 이 표는 탭과 무관하게 항상 보입니다 (리더보드 보다가도,
    CSV 올리다가도 위에 그대로 떠 있음).

  [상위 요약 카드]
  · 예측 대회 순위 1~4위 팀을 메달과 함께 요약 표시.

  [탭 1] 🏆 리더보드
  · 전체 참가 팀 순위. 팀을 클릭하면 그 팀이 어떤 경기를
    맞히고 틀렸는지 조별로 나눠서 자세히 볼 수 있습니다.
  · "🔄 새로고침" 버튼으로 최신 상태를 다시 불러올 수 있습니다
    (다른 팀이 방금 제출했다면 이걸 눌러야 반영됩니다 — 자동
    새로고침 기능은 없습니다).

  [탭 2] 📤 CSV 업로드
  · 팀 이름 입력 + 예측 CSV 파일 선택 + "제출하기".
  · 필수 컬럼: team1, team2, team1_score, team2_score,
    team1_prob, team2_prob (팀 이름으로 경기를 찾아서 채점하므로
    경기 ID 같은 건 몰라도 됩니다. 두 팀 순서가 바뀌어도 상관없음.)
  · 같은 팀 이름으로 다시 제출하면 기록이 새로 추가됩니다
    (덮어쓰기 아니라 누적 — 제출 기록을 다 볼 수 있음).
  · "예시 파일" 다운로드 버튼으로 형식을 미리 확인할 수 있습니다.
  · 제출에 성공하면 자동으로 리더보드 탭으로 이동해서 결과를
    바로 보여줍니다.


[ 3 ] 채점 기준 요약
───────────────────────────────────────────────────────────────
  🎯 10점 : 두 팀 스코어를 정확히 맞춤 (무승부도 포함)
  ✅  6점 : 한 팀 스코어 정확 + 승부 결과도 맞음
  ⭕  3점 : 한 팀 스코어만 맞고 승부 결과는 틀림
  🔵  1점 : 스코어는 틀렸지만 승/패/무는 맞춤
  ❌  0점 : 전부 틀림

  동점자가 나오면 10점 맞힌 횟수 → 6점 → 3점 → 1점 순으로
  비교해서 순위를 가립니다. 그래도 완전히 같으면 공동 순위로
  처리됩니다 (예: 공동 2위가 있으면 다음은 4위로 건너뜀).


[ 4 ] 문제가 생겼을 때
───────────────────────────────────────────────────────────────
  · "방금 고친 게 반영이 안 돼요" / "에러가 떠요"
    → 사이트 우측 하단 "Manage app" → "Reboot app" 으로 강제
      재시작. (단, 1번 항목 — 커밋 안 된 데이터 있는지 먼저 확인!)

  · "제출했는데 리더보드에 안 보여요"
    → "🔄 새로고침" 버튼을 눌러보세요. 자동으로는 갱신되지
      않습니다.

  · "팀 이름을 못 찾았다는 경고가 나와요"
    → CSV의 team1/team2 철자가 매치 목록과 다른 경우입니다.
      조별리그 순위표에 나온 팀 이름 표기를 그대로 쓰면 됩니다.
